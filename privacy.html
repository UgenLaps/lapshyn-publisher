Lapshyn Publisher

Privacy Policy

Last updated: October 21, 2026

1. Summary

Lapshyn Publisher is a private tool that uploads the owner's own videos to the owner's own accounts. It does not collect personal data about anyone else.

2. What data the tool uses

  • Access tokens that TikTok, Instagram and YouTube issue when the owner connects his own accounts. They are stored only in a protected file on the owner's own computer and are sent only to the platform that issued them.
  • Basic account information of the owner's own accounts (account ID, username), used only to make sure a video goes to the right account.
  • Videos and captions created by the owner, which the tool uploads at his request.

3. What the tool does not do

It does not read, collect or store data about viewers, followers or any other users. It does not use cookies or analytics, does not show ads, and does not sell or share data with anyone.

4. Websites

This website is a static page hosted on GitHub Pages. GitHub may keep standard server logs, as described in the GitHub Privacy Statement.

5. Removing access

The owner can remove the tool's access at any time in the settings of each platform (for TikTok: Settings and privacy, Security and permissions, Apps and services permissions). Stored tokens are then deleted from his computer.

6. Children

The tool is not directed at children and is not used by children.
